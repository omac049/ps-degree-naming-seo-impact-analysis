Six Rules for Every Group B Piece

Each rule comes from a Group A result, not a best-practice list. Apply all six to every brief.

1. Lead with the exact search phrase. Put the primary keyword first in the title tag and H1, then the payoff. Evidence: the MPS post reached page 1 for "mps degree" in six weeks but won 0.15% of clicks because the phrase was buried.
2. Answer in the first 50 words. Define the term or answer the question before any preamble; expand after. Evidence: two-thirds of blog clicks are mobile (24.1K of 35.8K).
3. Every BA rename gets an "Old Name vs New Name" piece. Comparison table, FAQ block, both names in the meta. Exception: MPS-CH is a launch — comparisons may educate, but never say “formerly MPH.” Evidence: Business Economics vs Business Administration was the top Group A page (346 clicks, 62.7K impressions).
4. Refresh before you write new. Where a UAGC post already ranks for the target, update it instead of publishing a competitor to it. Evidence: 3 refreshes = 685 clicks; 15 new posts = 569.
5. Use both names for 6–12 months on BA renames only. Meta, first paragraph, and one H2 carry old + new together (“formerly…”). Do not apply this pattern to MPS-CH. Evidence: current names still hold ~13,900 monthly searches; proposed names hold ~50. Strategy V3 launch guardrails for MPS-CH.
6. Link it in on day one. Program page → post, post → program page, post → one existing Professional Studies post. Evidence: the existing BPS vs BA post still carries 22K impressions for Professional Studies queries — borrow that authority.

How to Read This Plan — Origin & Update Types

Every row is either a new URL or an existing post. Existing posts use one of four update depths — pick the chip, then do only that scope. Do not open a FULL REFRESH brief when the row says TERM PASS.

NEW
New URL — does not exist yet Write the full piece (1,000–1,800 words per spec). Publish a new /blog/… slug. Most of Wave 1 Tier 1–2.

Effort: full brief + draft + SEO QA.

FULL REFRESH
Existing URL — rewrite hard Retitle (exact search phrase), restructure H2s, update salaries/data, add Applied or launch section, FAQ. Same slug.

Effort: near-new draft on the live URL. Group A’s highest-ROI move.

RENAME PASS
Existing URL — fix the program name Title, meta, H1, opener, and CTAs carry dual-name (BA renames) or MPS-CH launch guardrails. Not a full rewrite of body sections.

Effort: half-day. Use when the old name is still in the title.

TERM PASS
Existing URL — light language Body/CTA only: Applied dual-name, AA→60 credits, Sociology sunset note, or MPS-CH “distinct program” line. Structure stays.

Effort: 1–2 hours. No retitle unless a factual error.

META ONLY
Existing URL — surgical SERP fix Title tag + meta (+ optional H2). Paste-ready copy in the Pre-flight section.

Effort: under one hour. MPS degree guide.

HOLD
Do not publish Wave 2 / Carnegie / paused Business Admin / ECD Differentiated rename. Draft only until catalog confirms.

Inventory kept so we do not forget these URLs.

Spec for every piece

Title tag
≤ 60 characters. Exact primary phrase first, then the payoff. No "| UAGC" if it pushes past 60.
Meta description
145–155 characters. Names the four things the page delivers. Old + new program name for 6–12 months.
H1
Matches the title tag.
Opening
Direct answer or definition in the first 50 words. Both program names in the first paragraph where a rename applies.
Structure
4–6 H2s in the searcher's language. Comparisons: side-by-side table. Careers: one H2 per role or role group, BLS pay with link.
FAQ
5–8 questions pulled from People-Also-Ask; FAQ schema on comparisons.
Length
Explainers 1,000–1,500 · Comparisons and careers 1,200–1,800 · P3 "vs" pieces 800–1,000.
Internal links
At least 3: the program page, one related Group B piece, one existing Professional Studies post (professional-studies-vs-ba-or-bs-bps-vs-ba, what-professional-studies-degree, or professional-studies-degree-respected).
Citations
2–3 authoritative external sources (BLS, accreditor, peer-reviewed).
CTA
2 RFI placements: after the opening answer and at the close. Program-page link mid-page.
URL
/blog/what-is-[topic], /blog/[old]-vs-[new], /blog/[topic]-jobs. Refreshes keep their existing URL.
Voice
Student-first ("you"), grade 8 reading level, Oxford comma, title case H1/H2, sentence case H3+.

Publish-day checklist (Web Team + SEO)

  • Title, meta, H1, and og:title / og:description entered exactly as briefed — no auto-generated og:description.
  • Canonical is self-referencing; URL matches the brief (refreshes keep the old URL).
  • Page appears in /blog/sitemap.xml; submit the URL in Search Console.
  • Link added from the program page and the related-articles block to the new post.
  • Post links to the program page and to at least one Professional Studies post.
  • FAQ schema validates (comparisons); no duplicate H1/H2 text.
  • Mobile render checked — tables collapse, answer visible without scrolling.
  • Logged in the Group B tracker with publish date and target keyword.

How we'll know it worked

  • 14 days: indexed and receiving impressions for the primary keyword.
  • 90 days: page 1 for every zero-competition term (Tier 1 P1s, Tier 2 P1s).
  • Refreshes, 30 days: position improves ≥ 5 places on the primary keyword.
  • SEO reports weekly from Search Console; wins and misses feed the next brief.
